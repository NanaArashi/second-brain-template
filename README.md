# SecondBrain · 第二大脑模板

一套面向大学生的 Obsidian 个人知识库骨架：学科笔记分层、卡片间隔复习、自定义复习看板、可选资讯 / 科研情报与课件解析流水线。仓库只含结构、模板、样式与代码，**不含任何个人笔记与账号凭证**。

## 快速开始（给使用者）

1. 克隆本仓库，用 Obsidian 打开这个文件夹作为库。
2. 设置 → 第三方插件：安装并启用 **Dataview、Minimal Settings、Hider**；外观里启用两个 CSS 片段（`checklist-notes`、`minimal-warm-paper`）。
3. 照 `09_templates/` 里的空白模板建自己的日记、卡片和学科主笔记。
4. 打开根目录 `看板.md`，看板会自动扫 `07_subjects/` 下的卡片组成复习队列。
