# 看板数据流与配置

## 入口

根目录 `看板.md` 的 dataviewjs 块调用：

```dataviewjs
await dv.view("01_dashboard")
```

`01_dashboard/view.js` 分三层：
1. **collect\***：读日记、周计划、卡片、轨道、锚点等笔记与库外数据；
2. **render\***：拼 HTML 卡片；
3. **bind**：点击打开、打勾、记一笔、新建当日 / 当周笔记。

## 路径配置

`view.js` 顶部 `V` 对象是缺省路径；同目录 `config.json` 可覆盖（从 `config.example.json` 复制，`config.json` 已被 gitignore）。

| 键 | 缺省 | 说明 |
|---|---|---|
| `dailyDir` | `02_daily` | 当日日记目录 |
| `weeklyDir` | `03_weekly` | 周复盘目录 |
| `planPath` | `04_learning/plan.md` | 周计划总表 |
| `stackPath` | `04_learning/技术栈.md` | 技术栈路线 |
| `rhythmPath` | `04_learning/周节奏.md` | 周节奏 |
| `tracksDir` | `06_tracks` | 长期轨道目录 |
| `anchorsPath` | `05_goals/目标锚点.md` | 目标锚点卡数据源 |
| `subjectsDir` | `07_subjects` | 学科目录根 |
| `materialsDir` | `08_materials` | 原件目录 |
| 模板路径 | `09_templates/` | 新建日记 / 周计划的模板 |

## 卡片开关

`config.json` 两个开关，取值 `false` / `"placeholder"` / `true`：

| 键 | 作用 |
|---|---|
| `news` | 资讯卡。`false` 关；`"placeholder"` 空框架；`true` 接 `news/fetch.mjs` |
| `research` | 科研情报卡。取值同上，接 `research/fetch-research.mjs` |

不配 `config.json` 时用缺省值；缺省两个都是 `"placeholder"`，不接外部数据也不会崩。

## 轨道卡

`06_tracks/` 下每个文件夹：
- `README.md` frontmatter：`track`（轨道名）、`stage`（当前阶段）、`checkpoint`（下一节点）、`nextCheckpoint`（日期）；
- 可选 `周任务.md`（阶段任务与周安排）、`错题本.md`（条目堆叠）。

## 目标锚点卡

`05_goals/目标锚点.md`：二级标题是锚点；锚点下三级标题「里程碑」下的勾选项作为里程碑条目；开头 `- 字段: 值` 读为备注与窗口。
