# 环境与可选模块

## 必装（看笔记、跑看板）

1. **Obsidian**：把克隆下来的文件夹作为库打开。
2. **社区插件**：Dataview、Minimal Settings、Hider（在设置 → 第三方插件里安装启用）。
3. **CSS 片段**：`.obsidian/snippets/` 下 `checklist-notes.css`、`minimal-warm-paper.css`，在外观设置里启用。

## 可选：资讯 / 科研情报脚本

- 运行环境：**Node.js**。
- 密钥：环境变量 `ARK_API_KEY`（火山方舟）。不配也能看空框架，只是不接模型总结。
- 数据目录（库外，首次运行自动建）：`~/.secondbrain-news`、`~/.secondbrain-research`。
- 脚本：`news/fetch.mjs`、`research/fetch-research.mjs`；看板卡开关见 `docs/看板数据流与配置.md`。

## 可选：课件解析流水线

- 运行环境：**Python 3** + `python-pptx`。
- 入口：`01_dashboard/pipeline/run_pipeline.py`（Windows 可双击 `运行流水线.cmd`）。
- 口径：AI 只读 `08_materials/_收件箱/` 按学科分子目录的课件，产出速查卡 / 原子卡到对应学科目录；处理完原件归档到 `_已处理/`。
- 上线前先按自己的方向改 `pipeline/pipeline_config.py` 的 `SUBJECTS` 和提示词口径；`run_pipeline.py` 里保留了一门课的专用提示词分支，按自己的课程替换或删掉。

## 环境变量速查

| 变量 | 作用 |
|---|---|
| `ARK_API_KEY` | 方舟模型密钥，资讯 / 科研 / 流水线共用 |
| `SB_ARK_MODEL` | 可选，覆盖默认模型 ID |
| `SB_NEWS_DIR` / `SB_RESEARCH_DIR` / `SB_KB_DIR` | 可选，覆盖库外数据目录位置 |

## 仓库本身不带什么

- 课件、真题、论文原件；
- 账号凭证、`.env`、本机工作区布局；
- 插件可执行代码、Obsidian 本体、Node / Python 运行时。
