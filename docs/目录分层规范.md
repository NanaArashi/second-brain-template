# 目录分层规范

库根即 Obsidian 库目录。编号前缀决定阅读顺序；目录名保持不变，看板脚本按这些路径读取。

| 目录 | 职责 | 放什么 |
|---|---|---|
| `01_dashboard/` | 看板与自动化 | `view.js` 看板逻辑、`view.css` 样式、`fonts/` 字体、`news/` 资讯脚本、`research/` 科研情报脚本、`pipeline/` 课件解析流水线 |
| `02_daily/` | 每日日记 | 当天待办、执行记录、顺延池；文件名 `YYYY-MM-DD.md`，模板见 `09_templates/daily.md` |
| `03_weekly/` | 周复盘 | 每周一篇，文件名周一日期 `YYYY-MM-DD.md` |
| `04_learning/` | 学习层 | `plan.md` 周计划总表、`课程现状.md` 进度唯一真源、`周节奏.md`、`技术栈.md` |
| `05_goals/` | 目标层 | `目标锚点.md`：升学 / 竞赛 / 能力等长期锚点与里程碑 |
| `06_tracks/` | 长期轨道 | 每个长期项目一个文件夹（README + 可选周任务、错题本） |
| `07_subjects/` | 学科层 | 每门课一个目录，内部结构见 `07_subjects/_模板.md` |
| `08_materials/` | 原件层 | 课件、真题、论文 PDF/PPTX；**不进 git**，流水线收件箱 `_收件箱/` |
| `09_templates/` | 模板层 | 日记、周计划、速查卡、原子卡、学科主笔记空白模板 |
| `10_side/` | 副业 / 其他长期想法 | 与主线学习分开存放 |

## 命名约定

- 学科目录名与 `08_materials/` 下收件箱子目录名必须一致，流水线按目录名定科。
- 卡片文件名 = 卡片主题；章节讲义 `第N章_<主题>.md`；题型概括 `第N章_题型与套路.md`。
- 下划线开头的目录（`_归档`、`_模板`）不计入看板科目列表。
- 链接用双链 `[[笔记名]]`；跨层引用优先用双链，不写死绝对路径。

## 进度真源

各科主笔记、索引里的进度只引用 `04_learning/课程现状.md`，不要在多处重写进度，避免漂移。
