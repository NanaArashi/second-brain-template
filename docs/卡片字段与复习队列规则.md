# 卡片字段与复习队列规则

看板「待复习队列」自动扫描 `07_subjects/<学科>/速查卡/` 与 `07_subjects/<学科>/产出/原子卡/`，按间隔到期出现在今天的队列里。

## 速查卡 frontmatter

```yaml
---
cssclasses:
  - checklist-notes
subject: <学科目录名>
topic: <卡片主题>
last_review: <YYYY-MM-DD，可空；空则当天到期>
stage: 0
source: <课件 / 课堂笔记来源>
chapter: <章节号，可空>
order: <同章排序号，可空>
---
```

## 原子卡 frontmatter

```yaml
---
subject: <学科目录名>
type: 原子卡
topic: <一个独立卡住的实操点>
status: 待上机        # 待上机 / 概念已读 / 已验证
group: <题组或题号，可空>
source: <课件或习题来源>
---
```

## 进队列 / 不进队列

| 类型 | 是否进复习队列 |
|---|---|
| 速查卡 | 进 |
| 原子卡 | 仅 `status: 已验证` 才进；`待上机`、`概念已读` 不进 |
| `type: 检验` 的检验卷 | 永远不进 |

## 到期与间隔

- 复习间隔（天）按 `stage` 取值：`[1, 2, 4, 7, 15]`，stage 0→1 天，1→2 天，2→4 天，3→7 天，4→15 天。
- 新卡没有 `last_review` 时当天到期。
- 点「已复习」：`stage + 1`（封顶 4），`last_review` 写今天，当场从队列拿掉。
- 过期天数 = 今天 - 到期日；卡片上标「过期 N 天 / 今天到期 · 上次复习日期 · 第几档」。

## 卡型分工

- **章节讲义**：体系化提纲、定义定理推导、题型选型树；不进队列。
- **速查卡**：定义、公式、定义点碎片，碎而快，进队列反复刷。
- **原子卡**：一个实操卡点的最小 Demo + 讲解 + 易错 + 变体；验证过才进队列。
- **题型概括**：题目信号 → 解题路径 / 证明骨架；错题题号回查，不进队列。
