# 学科目录模板

在 `07_subjects/` 下为每门课建一个目录，内部结构：

```
<学科名>/
├── _主笔记.md          # 见 09_templates/学科主笔记.md
├── _地图.md            # 可选，体系结构图 / Canvas 双链
├── _模板.md
├── 速查卡/             # 进复习队列
├── 产出/
│   ├── 章节主笔记/
│   ├── 原子卡/         # 仅「已验证」进复习队列
│   └── 题型与证明套路.md
└── 画布/               # 可选，.canvas 文件
```

- 下划线开头的目录（`_归档`、`_模板`）不计入看板科目。
- 卡片字段与队列规则见 `docs/卡片字段与复习队列规则.md`。
